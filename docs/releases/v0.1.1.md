# v0.1.1 — Licensing, CI, and Portfolio Polish

Final non-algorithmic polish release of the Version-Aware RAG MVP.

- Adds the MIT License for the project's original code and consistent package
  license metadata; upstream Pydantic notices remain unchanged.
- Adds credential-free GitHub Actions CI on Python 3.12 for tests, lint, format,
  strict typing, and offline acquisition/extraction verification.
- Improves the portfolio resume bullets, repository description/topics and CI badge.
- Updates package version and current installation links to 0.1.1.

No retrieval or generation algorithm, model, prompt, schema, setting, label or
corpus change. All frozen v0.1.0 experimental results remain unchanged: held-out
RRF Recall@5 **.8111**, MRR **.8333**, and three qualitative generation checks
with **3/3 decision matches and 3/3 reviewed-valid citations**, not answer accuracy.
Cross-Encoder remains an ablation; retrieval UFPR remains 1. All 38 corpus
applicability assertions remain pending human review. No held-out retrieval or
paid generation was rerun. The v0.1.0 tag, release, assets and historical notes
remain available and untouched.

## Install

Use Python 3.12 (tested; package requires ≥3.12):

```sh
python -m pip install "version-aware-retriever[dense] @ https://github.com/meiming2019-web/version-aware-retriever/releases/download/v0.1.1/version_aware_retriever-0.1.1-py3-none-any.whl"
```

The same pinned external dense-model cache is required for context-only retrieval;
weights are not bundled. See README for preparation and CLI commands.

Assets: wheel, source distribution, SHA256SUMS and these release notes. Both
distributions include the root MIT License. Wheel data remains runtime-only;
benchmark gold, reviews and results are excluded. Third-party source material
retains its original notices/licenses; model and provider terms remain separate.
