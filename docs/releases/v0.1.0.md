# v0.1.0 — Version-Aware RAG MVP

First usable GitHub release of the bounded Pydantic migration RAG project.

- Frozen BM25 + pinned dense encoder → equal-weight RRF → Top 5.
- Grounded structured answers with source-linked citations or INSUFFICIENT_EVIDENCE.
- 34 evidence units; 16 held-out questions and 544 explicitly human-reviewed pairs.
- Held-out RRF Recall@3 **.7833**, Recall@5 **.8111**, MRR **.8333**.
- Cross-Encoder remains an ablation: less observed wrong-version exposure, but
  lower held-out Recall@3/5 and MRR. One negative pair does not establish broad correctness.
- Three frozen generation examples: two SUPPORTED and one INSUFFICIENT_EVIDENCE;
  **decision matches 3/3, reviewed-valid citations 3/3**, not answer accuracy.
- Installable wheel with immutable hash-checked corpus/provenance resources,
  original upstream notices and the `version-aware-retriever` console CLI.
- Deterministic offline tests, clean-install acceptance and safe TLS diagnostics.

## Install

Use Python 3.12 (tested); package metadata requires ≥3.12:

```sh
python -m pip install "version-aware-retriever[dense] @ https://github.com/meiming2019-web/version-aware-retriever/releases/download/v0.1.0/version_aware_retriever-0.1.0-py3-none-any.whl"
python -m version_aware_retriever.dense prepare
version-aware-retriever --query "In Pydantic 2.5.3, how do I validate a dictionary into a model?" --context-only
```

Preparation downloads the fixed external snapshot; weights are not bundled.
Generation requires OPENAI_API_KEY and OPENAI_MODEL=gpt-5.6-sol. It sends the query
and five excerpts to OpenAI and may incur charges. No paid experiment is rerun
for this release. See README for source validation, reproduction and safe TLS setup.

Assets: wheel, source distribution, SHA256SUMS and these notes. Checksums cover
the wheel and sdist. Wheel data excludes gold/review/results and raw sources;
the sdist retains reproducibility data. Not published to PyPI.

## Limits and licensing

Single ecosystem, small/shared corpus, single explicit human batch review of
AI-assisted annotations, one reviewed held-out wrong-version pair, uncalibrated
generation abstention and no production readiness claim. Retrieval UFPR remains 1.
All 38 corpus applicability assertions remain pending human review.

No root license was selected for this project's own code. Public release is not
an open-source license grant. Pydantic excerpts retain upstream MIT notices;
model/provider terms are separate. No frozen metrics, labels, prompts, outputs
or retrieval settings were changed for shipping.
