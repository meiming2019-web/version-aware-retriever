## Input, cache, and ranking policies

Immediately project evidence to ID, ecosystem, content using the BM25 helper.
Read only the public development input file, not authoring drafts or judgments.
Encode only original content and query_text, with no metadata concatenation or
new chunks. Published ST Transformer preprocessing strips surrounding whitespace;
no custom lowercasing, prompts, or BM25 tokenizer. The actual pinned tokenizer
measures all inputs with special tokens and no truncation before any encoding.
Runtime checks confirm the published pooling, prompts, lowercasing setting, and
limit. Oversized inputs fail with ID and length instead of truncating or splitting.

The real 34-document/eight-query pass succeeded: maximum document **1061 tokens**,
query **47 tokens**, **zero truncations**; vector shapes **34×768** and **8×768**.
Each document is encoded once per pass, then reused across all queries.

The ignored `.dense-cache/` contains a small plain JSON embedding artifact (no
pickle or executable deserialization). It retains float32 encoder values as JSON
numbers, ordered IDs, a hash of exact ordered texts, token counts, configuration,
package versions, and a hash over the entire payload. Cache reuse rejects binding
or payload mismatches, misalignment, invalid dimensions, nonfinite/zero vectors,
and invalid token counts. It is an experiment cache, not an authenticated archive.

ST produces L2-normalized float32 embeddings. Vector scoring renormalizes using
Python float64 arithmetic and computes the exact dot product with `math.fsum`.
Full ranking keeps zero/negative values; descending unrounded score, then ascending
evidence ID on exact ties. Optional k is None or a nonnegative integer (not bool).
Empty vector corpora yield no hits; invalid/empty query vectors fail. Public query
contracts reject blank text. No guessed similarity threshold or learned abstention
is applied. Cosine is neither probability, answerability, nor version applicability.

The unscored run has all eight RankedResult-shaped rows and 34 aligned finite
scores per row, artifact hashes, encoder/runtime details, embedding identity, and
the same projected retrieval-input snapshot as BM25. No benchmark_revision is
invented. Annotation-only changes cannot affect vectors, rankings, or run identity;
the full input artifact hash still records that provenance change.

## Checks and limits

Synthetic tests exercise hand-calculated positive/zero/negative cosine scores,
normalization, invalid vectors/dimensions/counts, ties, k, empty inputs, ID alignment,
token limits before encoding, metadata isolation, guarded input access, cache
staleness/integrity, and repeat scoring. No pytest test downloads a model.

The first real local-only encoding succeeded. Cached rescoring produced identical
run/cache bytes and nanosecond modification times. Fresh-encoding comparison uses
an absolute tolerance of **1e-6**, set before the repeat, and compares complete
ranking order separately. Neural inference is not promised byte-identical across
environments. No documentation examples were executed and no runtime claims about
Pydantic were tested. Real annotation review and formal benchmark acceptance remain
incomplete.

The separate fresh pass completed: maximum absolute vector difference **0.0**,
maximum score difference **0.0**, all eight full ranking orders equal; both run
and embedding JSON bytes also matched. This is an observation in the recorded
environment, not a cross-platform guarantee. Both encoding processes emitted a
tokenizers fork warning and automatically disabled tokenizer parallelism; neither
failed. A display-only comparison initially used the wrong envelope key
(`inspection_key` instead of `key`); correcting that join did not change rankings.
